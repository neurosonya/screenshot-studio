# Скриншот-студия

Mac-приложение и редактор в браузере для оформления скриншотов. Делает из
обычного скриншота красивую картинку: прозрачный или градиентный фон, отступы,
мягкая объемная тень, скругленные углы, мокап браузера, стрелки и подписи.

**Работает бесплатно и офлайн.** Никаких аккаунтов, лимитов, водяных знаков и
интернета - все считается на твоем Маке, ничего никуда не отправляется.

- **Открыть в браузере:** [neurosonya.github.io/screenshot-studio](https://neurosonya.github.io/screenshot-studio/) - ставить ничего не надо.
- **Скачать для Mac:** файл `.dmg` в [последнем релизе](https://github.com/neurosonya/screenshot-studio/releases/latest).

## Что в репозитории

- `index.html` - весь редактор одним файлом. Работает в любом браузере на любом
  компьютере, можно скачать и открыть без интернета.
- `app/` - исходники Mac-приложения на Swift и скрипт сборки `app/build.sh`.
- Готовое приложение (`.dmg`) лежит в релизах, в репозитории его нет.

## Установка на Mac

1. Скачай `.dmg` из [последнего релиза](https://github.com/neurosonya/screenshot-studio/releases/latest),
   открой и перетащи `Скриншот-студия.app` в «Программы».
2. Первый запуск: **правой кнопкой по приложению -> Открыть -> Открыть**. Mac
   скажет «не удается проверить разработчика» - приложение подписано без
   платного аккаунта Apple Developer. Это делается один раз, дальше
   запускается как обычно.
3. Mac может спросить разрешение на запись экрана - это для кнопки «Снять
   область», нажми «Разрешить».

Приложение живет и в строке меню (значок с рамкой сверху справа): оттуда можно
снять область экрана или открыть студию, даже если окно закрыто.

## Как пользоваться

1. **Добавь картинку** - перетащи файл в окно, вставь из буфера (Cmd+V),
   «Файл -> Открыть» (Cmd+O) или сними область экрана (Cmd+Shift+A, а из любой
   другой программы - Ctrl+Option+S).
2. **Фон** - во вкладке «Цвет» первый квадратик с шахматкой - это **прозрачный
   фон**: скриншот будет парить на любом фоне, где ты его вставишь. Либо
   градиент, сплошной цвет или своя картинка.
3. **Настрой красоту** - отступ, тень (она объемная, из двух слоев), скругление,
   подложка, обводка, мокап браузера.
4. **Формат** - Auto, пропорции или готовый размер под соцсеть (есть
   **Пин Pinterest 1000x1500**).
5. **Аннотации** сверху: стрелка, рамка, текст, эмодзи, карандаш.
6. **Экспорт** (Cmd+E) открывает обычное окно «Сохранить» - выбираешь папку и
   имя. PNG сохраняет прозрачность, JPG подкладывает белый фон.
   «Копировать» (Cmd+Shift+C) кладет картинку в буфер - сразу вставляй в пост.

## Горячие клавиши

| Действие | Клавиши |
|---|---|
| Открыть картинку | Cmd+O |
| Снять область экрана | Cmd+Shift+A (из любой программы: Ctrl+Option+S) |
| Вставить картинку из буфера | Cmd+V |
| Экспорт | Cmd+E |
| Копировать результат | Cmd+Shift+C |
| Сохранить проект | Cmd+S |
| Новый снап | Cmd+N |
| Отменить аннотацию | Cmd+Z |
| Удалить выбранное | Delete |
| Масштаб: по окну / 100% / 200% | Cmd+0 / Cmd+1 / Cmd+2 |
| Инструменты | V выбор, R прямоугольник, O круг, L линия, A стрелка, T текст, P карандаш |

Подсказка со списком есть и в самой программе - кнопка «?» справа вверху.

## Мелочи, которые пригодятся

- **Подвинуть или удалить аннотацию**: инструмент «Выбор» (V), кликни по ней,
  тащи мышкой или жми Delete. **Поменять текст** - дважды кликни по нему.
- **Цвет и толщина** аннотаций - в верхней панели. Если что-то выделено,
  меняется прямо у него.
- **Мои снапы** внизу левой панели - сохраненные проекты, можно открыть и
  доредактировать. Лимита нет.
- Картинку можно открыть и из Finder: правой кнопкой -> «Открыть в программе»
  -> Скриншот-студия.

## Собрать приложение самостоятельно

Нужен Mac с установленными инструментами командной строки Xcode
(`xcode-select --install`). Из папки проекта:

```bash
bash app/build.sh
```

Готовое приложение и DMG появятся в `dist/`. Редактор внутри приложения - тот
же `index.html`: поменяй его и пересобери.
